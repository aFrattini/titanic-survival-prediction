## 📊 Titanic Survival Prediction
Este repositorio contiene el notebook de análisis y modelado predictivo del dataset del Titanic. El proyecto forma parte de mi portfolio personal y está diseñado para mostrar mis habilidades en análisis de datos, aprendizaje automático y despliegue de modelos.

## 📁 Contenido del repositorio
- Titanic_Notebook.ipynb → Notebook completo con el análisis exploratorio de datos (EDA), preprocesado, entrenamiento de modelos, comparativa y exportación.

- ml_models/ → Carpeta con los modelos entrenados guardados en formato .joblib.

- requirements.txt → Lista de librerías necesarias para ejecutar el notebook.

- README.md → Este archivo.

## 💻 Descripción del proyecto
El objetivo es predecir la probabilidad de supervivencia de los pasajeros del Titanic utilizando modelos de aprendizaje supervisado.
Se trabajó con el dataset original de Kaggle, realizando:

- Carga y exploración de datos.

- Análisis de valores faltantes y outliers.

- Limpieza y transformación de variables (codificación de variables categóricas).

- Entrenamiento y evaluación de varios modelos:

    - Regresión logística

    - Árboles de decisión

    - Random Forest

    - K-Nearest Neighbors

- Exportación de modelos en formato .joblib para integrarlos en un portfolio web interactivo.

## 📈 Uso de los modelos
Los modelos exportados son utilizados en mi portfolio web para que los visitantes puedan probar predicciones en tiempo real, simulando un caso práctico de despliegue en producción.

## 📦 Instalación

1. Clona el repositorio:

```
git clone https://github.com/tu-usuario/titanic-prediction.git
cd titanic-prediction
```

2. Instala las dependencias:

```
pip install -r requirements.txt
```

3. Ejecuta el notebook en Jupyter o VSCode.
